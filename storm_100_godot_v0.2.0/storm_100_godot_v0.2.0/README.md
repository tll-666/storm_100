# 暴雨100天 · Godot正式工程

这是从HTML原型转入Godot后的正式工程。当前版本为 **0.2.0 灾前第一次购物闭环**。房屋灰盒仍然保留，并在此基础上接入社区超市、220元预算、10格后备箱、结账回家和四位家人的轻微反应。

0.1.1修复了Godot 4.7新增原生`draw_ellipse()`后，与人物阴影辅助函数发生的签名冲突。0.2.0不加入暴雨和接人，专门验证第一天的购物选择是否成立。

## 使用环境

- Godot 4.7 Standard（非.NET版）
- GDScript
- GL Compatibility渲染器，便于后续导出Windows和Web试玩版

## 启动

1. 打开Godot项目管理器。
2. 点击“导入”，选择本目录中的 `project.godot`。
3. 导入后点击右上角运行项目，或按F6/F5。

## 操作

- `WASD` 或方向键：移动
- `E`：靠近人物或家具后互动
- `Esc`：关闭当前对话
- `F5`：保存检查点
- `F9`：读取检查点

## 当前可测试内容

- 一楼、前院、车道和住宅街使用同一张连续地图。
- 二楼包含三间卧室功能区、二楼厕所、楼梯平台和车库上方的公共阳台。
- 镜头跟随玩家，房屋尺寸已经大于单屏。
- 关键家具拥有碰撞和检查文本。
- 四位家人可以互动，每人的回应只能选择一次，重复交谈会显示对应回话。
- 楼梯可以在一楼和二楼之间切换。
- F5/F9会保留楼层、位置、已检查家具以及对话选择。
- 与四位家人交谈并检查至少5处关键位置后，可以从车库开车去社区超市。
- 超市有主食、蔬菜零食、日用品、电池充电、常用药和饮料冷柜。
- 购物受220元预算和10格后备箱共同限制，大件物资会占用2格。
- 收银台可以拿出最后一件商品，也允许玩家决定什么都不买。
- 回家后，家人会根据买回来的东西给出简短反应；影响轻微，不改变主线。

## 这一版刻意没有做

- 最终人物和家具美术
- 接人路线场景
- 暴雨粒子、雷声和积水
- 每日食物、饮用水和电力结算
- 最终物价和平衡数值

这些内容会在房屋灰盒确认后继续加入同一工程。

## 首次测试请重点观察

1. 房间是否仍显得过小或过空。
2. 家具之间的通行宽度是否自然。
3. 镜头距离是否适合寻找互动点。
4. 一楼到前院、车库、二楼阳台的动线是否符合真实住宅。
5. 对话框是否遮挡过多画面。
6. 220元和10格限制是否真的让你需要取舍。
7. 购物后四位家人的反应是否自然、是否过于明显。

# 房屋布局与交互原则

## 结构理由

- 街道位于房屋正面，玩家能从前院和二楼公共阳台观察外部。
- 车库位于一楼前侧，地面低于住宅区域，后期最先积水。
- 客厅和餐厅是家庭事件中心，楼梯位于公共区域。
- 老人卧室位于一楼，靠近厕所和主要生活区。
- 一楼厕所/洗衣区与二楼厕所上下叠放，共用管线逻辑。
- 公共阳台位于车库上方，从楼梯平台进入，不需要穿过私人卧室。

## 家具分级

互动家具必须至少承担一种作用：

1. 储存物资；
2. 执行行动；
3. 显示房屋状态；
4. 触发事件；
5. 提供人物情绪或剧情信息。

没有功能的小摆件只作为背景绘制，不单独设置互动和碰撞。

## 当前灰盒互动点

- 一楼：汽车、车库排水口、冰箱、食品柜、收音机、厕所/洗衣区、配电箱、住宅街。
- 二楼：阳台排水口、阳台观察点、大孩子书桌、小孩子玩具柜。
- 人物：伴侣、老人、大孩子、小孩子。
- 交通：一楼楼梯、二楼楼梯。

灰盒确认后才添加最终家具贴图、室内装饰和天气美术。

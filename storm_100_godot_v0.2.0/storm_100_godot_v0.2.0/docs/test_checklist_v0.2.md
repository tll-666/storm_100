# 0.2.0首次测试清单

请使用Godot 4.7 Standard运行项目，按以下顺序测试：

1. 与伴侣、老人、大孩子和小孩子分别交谈，并为每人选择一个回答。
2. 重复与至少一位家人交谈，确认只显示对应的后续回话，不能重新选择。
3. 检查至少5处家具或关键位置。
4. 回到一楼车库，确认汽车提示变为“开车去社区超市”。
5. 进入超市，分别查看不同货架并拿取商品。
6. 尝试超过220元，确认提示钱不够。
7. 尝试超过10格，确认提示后备箱放不下。
8. 到收银台放回最后一件商品，再完成结账。
9. 确认回家后显示消费、余额和四位家人的简短反应。
10. 分别在家和超市按F5保存、F9读取，确认位置、购物篮和进度能够恢复。

第二轮可以直接空着购物篮到收银台，测试“什么都不买就回家”的结果。

测试时重点记录：

- 哪些商品明显不会考虑购买。
- 220元是否过多或过少。
- 10格限制是否容易理解。
- 超市货架之间的移动距离是否过长。
- 家人的反馈是否太明显、太长或不自然。

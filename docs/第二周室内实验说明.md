# 暴雨第8—15天扩展说明

> 当前状态：冻结、未实装。旧版第二周事件已全部作废，`rain_day_8.json` 与 `rain_day_9_15.json` 当前不包含正式事件。

## 为什么暂时留空

第一周新增了自然时间、中午逐人配给、食物变质、三层水质、两类净水器、滤芯、厕所自动化、地点发现和隐藏后果。应先验证这套循环是否好玩，再决定第二周需要哪些剧情，避免用文字事件掩盖机制问题。

## 解冻条件

- 第1—7天能够从第0天连续走通。
- 玩家能够理解水质、容器、食物倒计时和厕所状态。
- 第1天窗户选择能在第2天给出正确回响。
- 夜间总结不会泄露玩家未发现的原事件。
- 第7天的重复操作仍能产生资源取舍。

## 解冻后的内容顺序

1. 先增加一个完全室内的滤芯或食物压力事件，并在次日回应。
2. 再增加一个短小外出事件：从玄关进入独立事件场景，当天返回，次日用少量资源或状态变化闭环。
3. 最后才投放军方消息、造船工具或长期坚守提示，且三条路线不能在同一事件里同时开启。

在用户确认前，不把任何具体人物、邻居、军方空投或外出剧情写入正式数据。

# 暴雨第8—15天室内实验说明

本轮目标不是确定正式章节长度，而是让玩家连续跑过一段足以检验可玩性、资源压力和选择回响的内容。第8—15天暂时作为“第二周室内压力测试”。不实装任何离家外出。

## 每日压力与环境变化

| 日期 | 当日问题 | 玩家选择影响 | 当日或周期内回响 |
|---|---|---|---|
| 第8天 | 断电后的食品变质、最后干燥角落 | 用水抢救食物或止损；保护物资或床铺 | 当晚进入库存与房间结算 |
| 第9天 | 排水管道预警 | 提前封堵或只做水位记号 | 第13天污水反灌时兑现 |
| 第10天 | 二楼屋顶漏水 | 控制漏点或只转移物资 | 决定卧室是否继续可用 |
| 第11天 | 雨水收集与分类 | 过滤少量或保留较多非饮用水 | 当晚饮水结算直接使用储量 |
| 第12天 | 短暂小雨窗口 | 扩大睡眠区或整理物资区 | 改变房间状态或获得遗漏食物 |
| 第13天 | 污水反灌 | 加固封堵或放弃厕所 | 污染是否进入生活区立即确定 |
| 第14天 | 第7天广播与邻居判断 | 不再开启新判断，只确认旧消息边界 | 广播、目击和两手准备三条线闭合 |
| 第15天 | 阶段盘点 | 无新短期悬念 | 展示食物、水、健康和可用房间前后差值，结束版本 |

## 这段实验实际检验的机制

1. 食物不只减少，也会因停电变质；玩家可以用水换食物。
2. 房间状态会从潮湿、漏水、积水走向不可使用，核心后果是压缩生活空间。
3. 检查提供征兆。第9天是否处理管道不会决定灾害“发不发生”，只决定第13天来临时是否已有防线。
4. 饮水和生活用水有数量压力；雨水先以储量进入系统，同时在文字中明确用途和卫生边界。
5. 家庭压力尽量用行为表达，例如伴侣另记一份物资表，不为第二周新增独立“士气剧情”。
6. 第5—7天安排的孩子、配给、伴侣、邻居和广播延迟结果都在第15天前回收。
7. 每天仍使用一条连续时钟；剧情阅读暂停，世界容器操作不暂停，夜间结算与换日等待确认。

## 外出事件提案（未实装）

### 《桥下的蓝桶》

- 建议发生：第10天上午，雨势短暂减弱时。
- 可派人：玩家或大孩子；也可以谁都不去。
- 目标：到两条街外的公交站确认一个蓝色防水桶，不延伸到更大地图。
- 快速闭环：出发者当天下午返回，不跨夜失联。
- 收获概率保持小幅：常见结果为干饼干1包和瓶装水2升；坏结果是只带回空桶且健康小幅下降；不去则没有资源变化，但保留家庭劳动力。
- 周期内后果：第12天盘点时显示资源差值；若带回空桶，第13天可多接2升生活水；若带回食物，第14天少触发一次饥饿表现。
- 设计目的：完整测试“听到线索—选人—短途移动—搜索—回家—室内消耗回响”的最小外出循环，同时不把第一张外出地图和救援主线绑在一起。

该事件目前只保留为剧情与机制提案，没有加入事件JSON、地图入口或可触发阶段。

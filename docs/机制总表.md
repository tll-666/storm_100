# 暴雨100天 — 机制总表

## 原则

1. 每个事件都在跟系统对话。文字交代事实，数值表达结果。
2. 没有"情绪/氛围"等软数值。家人的压力通过**看得见的行为变化**表现（不吃饭、不说话、摔东西）。
3. 一家人会死。游戏不遮这个。但不突然——前面必然有征兆。
4. 每件事选项最多 3 个。至少 2 个。至少 1 个选项有明显代价。

---

# 一、供电系统

| 阶段 | 说明 | 触发条件 | 影响 |
|---|---|---|---|
| **正常** | 全屋有电 | 暴雨前 | 冰箱保鲜、灯、手机充电、抽水泵可用 |
| **不稳定** | 灯闪、电压低 | 入暴雨第 2 天 | 冰箱间歇停机，手机充电慢 |
| **停电** | 全屋失电 | 入暴雨第 2 天傍晚（强制触发，或延迟到第 3 天） | 冰箱停止、灯灭、手机只能靠充电宝 |
| **永久停电** | 电网无法恢复 | 停电后持续 | 同上，持续到灾害结束 |

**玩家可做的**：
- 每日动作「检查配电箱」→ 确认当前供电状态
- 使用备用电池 / 充电宝 → 消耗备用电力格数
- 本次循环不考虑发电机和外接电源（在家中无法外出购买）

**对系统的传导**：
- 冰箱停电 → 生鲜食品 3 天后变质（肉/奶/蛋/蔬菜）
- 无灯照 → 每天额外 -1 家庭整体状态（非数值，表现为成员更容易因小事争吵）
- 无充电 → 第 5 天后手机全体关机，失去外界信息

# 二、供水系统

| 阶段 | 说明 | 条件 | 影响 |
|---|---|---|---|
| **正常** | 自来水可用 | 暴雨前 | 饮用、做饭、洗漱、冲厕完全正常 |
| **低压** | 水龙头流量减少 | 入暴雨第 1 天，或第 2 天 | 接水需要更长时间，但不影响水质 |
| **变黄** | 水质开始变差 | 低压持续 2 天后 | 自来水不可直接饮用。可用于冲厕、擦洗。 |
| **停水** | 全屋停水 | 暴雨第 5 天后概率触发，或水泵/管道故障 | 所有家庭用水依赖储备水和雨水 |

**玩家可做的**：
- 每日动作「查看水龙头」→ 确认当前水质和水量
- 用水桶、锅、瓶等容器储水（需提前准备容器）
- 在阳台/窗口接雨水 → 每天可能获得 2-6 升雨水（不可饮用，可用于冲厕、擦洗）
- 使用储备瓶装水 / 储水桶中的水

**储备水说明**：
- 瓶装水：买来的，可直接饮用。消耗完后无补充。
- 储水桶里的自来水：暴雨前接的，停电前是干净的。但停电停水后无法补充。

**对系统的传导**：
- 停水 → 无法冲厕（详见污水系统）
- 缺水 → 家人每天饮水需求无法满足 → 脱水 → 健康下降（老人和小孩优先受影响）
- 储备水用完 → 只能靠雨水（不能喝）→ 必须拆瓶装水

# 三、潮湿与霉菌

**机制**：每个可居住区域（二楼卧室、客厅、储物角）有独立的**湿度等级**。

| 等级 | 名称 | 表现 | 健康影响 |
|---|---|---|---|
| 0 | 干燥 | 正常 | 无 |
| 1 | 微潮 | 墙面有凉感 | 老人关节不适，微弱 |
| 2 | 潮湿 | 墙根起皮、被褥发冷 | 所有成员每天 -1 健康（老人 -2） |
| 3 | 发霉 | 可见霉斑，气味刺鼻 | 所有成员每天 -2 健康，老人 -4，小孩 -2 |
| 4 | 严重霉变 | 大面积霉斑，衣物腐烂 | 房间不可居住 |

**湿度上升条件**：
- 连续下雨 → 全屋每天 +1 湿度（不可避免）
- 屋顶漏水 → 该房间 +2（不处理则每天持续上升）
- 一楼被淹 → 二楼湿度每天 +1（水汽上行）
- 窗户没封好 → 该房间 +1

**玩家可做的**：
- 每日动作「通风」→ 选一个房间，湿度 -1（只能延缓）。如果外面是暴雨则无效。
- 每日动作「擦墙 / 清理霉斑」→ 该房间湿度 -2，消耗玩家体力（健康 -1）。
- 修补屋顶漏水 → 堵住源头后该房间不再额外上升。

**对系统的传导**：
- 潮湿 → 食品加速变质（尤其干货：米、面、饼干）
- 发霉 → 成员生病概率上升（呼吸道感染）
- 严重霉变 → 该区域的被褥/衣物损毁

# 四、食品系统

### 食物分类

| 类型 | 物品 | 保质期（停电后） | 易受潮变质 |
|---|---|---|---|
| 生鲜 | 肉、蔬菜、牛奶、蛋 | 1-2 天 | 否 |
| 半耐放 | 罐头、巧克力 | 不受影响 | 否 |
| 干货 | 米、面、饼干 | 无电无潮可长期 | **是** |
| 饮用水 | 瓶装水、储水桶水 | — | 否 |

### 变质机制

- **生鲜**：停电后冰箱失温。第 3 天起，肉/蛋/奶/蔬菜腐烂，不可食用。
- **干货发霉**：如果存放区域湿度 ≥ 2，每个存储区域每天 20% 概率有一格干货发霉。发霉食品不可食用。
- **罐头**：不受影响。

### 每日消耗

每个成员每天消耗 **1 份食物**（不区分种类，按热量折算）。

实际消耗：
- 如果储存的份数 ≥ 家人数 → 正常消耗
- 如果不够 → 系统自动分配，先保证小孩，再老人，再别人。没分到的人饥饿值上升。

饥饿值累积（每个成员单独跟踪）：
- 饥饿 1 天 → 健康 -1
- 饥饿连续 3 天 → 健康 -3，工作效率下降
- 饥饿连续 5 天 → 健康 -5，老人和小孩进入危险状态
- 饥饿连续 7 天 → 死亡

### 每日可做

- 「盘点食物」→ 获知精确剩余份数、哪类食物已坏
- 「转移食物」→ 将容易受潮的干货从潮湿区域移到干爽区域
- 「烹饪」→ 将生鲜提前做成可储存的热食（延长 1 天保质期，但消耗水）

# 五、疾病系统

**不是"生病/不生病"二选一。是风险因子累积 → 触发疾病。**

### 风险因子

| 因子 | 来源 | 清除办法 |
|---|---|---|
| 受寒 | 被褥潮湿、停电无暖 | 干燥被褥、减少潮湿房间停留 |
| 饮水不安全 | 喝了自来水（变黄后） | 只喝瓶装水 / 储水桶里的清水 |
| 食物变质 | 吃了腐烂生鲜 / 发霉干货 | 不食用变质食品 |
| 营养不良 | 连续缺粮 | 恢复吃饱 |
| 污水接触 | 一楼被淹后涉水 | 尽量避免，涉水后清洗 |

### 触发规则

每天结算时，每个成员单独判断：
- 如果该成员有 ≥ 2 个风险因子持续 ≥ 2 天 → 触发疾病。
- 疾病类型取决于主导因子：受寒 → 感冒/肺炎；不洁饮水 → 肠胃炎；食物变质 → 食物中毒；污水 → 伤口感染。

### 疾病后果

- 轻度疾病：健康 -3/天，持续 2 天。自愈。
- 中重度：健康 -5/天，持续 3 天。需要药物干预。
- 重症（肺炎/严重感染）：健康 -7/天，如果不治疗 → 第 4-5 天死亡。

### 药品

家庭初始有：
- 感冒药 1 板（12 粒，1 人/1 天用量）
- 退烧药 1 板（6 粒）
- 消炎药 1 板（6 粒，专门针对感染/肺炎）
- 肠胃药 1 板（6 粒）

可以在暴雨前购物时补充。暴雨后无法补充（除非有特殊事件如邻居交易或物资发放）。

# 六、污水 / 厕所系统

暴雨对家庭的直接影响之一。一楼的厕所在水位上升到地面以上时排水反灌。

| 阶段 | 说明 | 触发 | 影响 |
|---|---|---|---|
| **正常** | 厕所可正常使用 | 暴雨前 | 无 |
| **排水缓慢** | 冲水后下水慢 | 一楼地面开始潮湿 | 勉强可用 |
| **反味** | 厕所返臭味 | 一楼水位上升 | 厨房和厕所区域不能久留 |
| **反灌** | 污水从马桶倒流 | 车库+一楼被淹等级 ≥ 2 | 一楼的厕所完全无法使用，卫生风险 |
| **二楼可用** | 二楼厕所可能还行 | 二楼厕所位置高 | 如果水压够可继续使用 |

### 影响

- 污水反灌 → 房屋内致病菌增加 → 所有成员疾病风险 +1
- 无法冲厕 → 只能用桶或阳台（卫生状况会加速恶化）
- 污水进入一楼 → 涉水变得危险（污水接触风险）

### 玩家可做的

- 「检查厕所」→ 确认当前状态
- 「用水桶冲厕所」（消耗储备水 2L/次）
- 「暂时封堵一楼厕所」→ 用塑料袋和胶带封住马桶，防止反灌（减少臭味和病菌）

# 七、房屋结构损伤

| 区域 | 损伤类型 | 诱因 | 后果 |
|---|---|---|---|
| 屋顶 | 裂缝/漏水 | 暴雨持续时间 | 对应房间湿度大涨 |
| 一楼外墙 | 渗水 | 外面积水高于室内地面 | 墙根起皮、结构逐渐软化 |
| 一楼地面 | 积水 | 车库倒灌 + 外墙渗水 | 地板泡烂、物品损毁 |
| 窗户 | 胶条老化 | 湿度 + 风力 | 灌雨灌风，该房间湿度 +2 |
| 楼梯 | 泡水 | 一楼水位 | 木质楼梯板损毁，上下楼困难 |

### 玩家可做的

- 每日动作「检查屋顶 / 墙面」→ 发现新漏水点
- 修补：胶带临时封堵 → 延缓；专业人员修补 → 需要事件（不可能有）。**这类主动维修只能治标不治本。**

# 八、家庭压力（简化版）

不用 morale 数值。用**行为变化**来表达。

| 阶段 | 表现 |
|---|---|
| **轻度压力** | 说话变少。孩子不画画了。 |
| **中度压力** | 有人不吃饭（老人）、有人待在阳台不进屋（伴侣）、有人摔/甩东西（大孩子） |
| **重度压力** | 某个成员要求离开家。或拒绝听从安排。 |
| **崩溃** | 有人离家（冒着暴雨走出去），或彻底停止配合。 |

压力上升条件：
- 连续缺粮 > 2 天
- 家人发病
- 某个成员连续被无视（选了太多次不理他的选项）
- 房间发霉到等级 3 以上
- 污水反灌

# 九、每天结算流程

```
午夜结算：
1. 食物消耗结算 → 检查库存是否 ≥ 人数
2. 饮水消耗 (每人 1L/天) → 检查储备水
3. 食品变质检查 → 过期/发霉的处理
4. 房间湿度变化 → 各房间 +1
5. 疾病风险累计 → 每个成员判断是否触发疾病
6. 房屋结构变化 → 检查是否有新漏水/裂缝
7. 家庭成员行为变化 → 根据累计压力判定
```

# 十、每日可重复动作

每个动作消耗一次"行动次数"。每天有 2 次行动（上午、下午），加上事件触发的选择不计入。

| 动作 | 效果 | 备注 |
|---|---|---|
| **查看水龙头** | 获知当前供水状态和水质 | 无消耗 |
| **检查配电箱** | 确认供电状态 | 无消耗 |
| **盘点食物** | 获知精确食物剩余和变质情况 | 无消耗 |
| **检查某房间** | 获知该房间湿度等级、有无新裂缝/漏水 | 无消耗 |
| **检查厕所** | 获知污水状态 | 无消耗 |
| **接雨水** | 获得 2-6L 雨水（不可饮用） | 需容器。阳台可做。 |
| **清理霉斑** | 选一个房间，湿度 -2 | 消耗玩家健康 -1 |
| **通风** | 选一个房间，湿度 -1 | 暴雨天无效 |
| **封堵漏水** | 临时封堵一个漏水点 | 消耗胶带 |
| **转移食物** | 将干货移到一个湿度低的区域 | 防止发霉 |
| **封堵厕所** | 防止污水反灌 | 消耗胶带+塑料袋 |
| **舀水** | 一楼水位暂时 -1 级 | 消耗玩家健康 -2。只能延缓。 |
| **查看老张 / 邻居** | 了解外部情况 | 阳台可做。有时无收获。 |
| **搜索家中** | 可能发现遗忘的物资 | 每天一次，成功率递减 |

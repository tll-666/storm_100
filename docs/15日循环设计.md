# 暴雨100天 — 15日循环：缓慢的崩溃

> 覆盖：暴雨第4天 ~ 暴雨第18天。所有引入的事件线都在此窗口内闭环。

---

## 主题与氛围

**主题**：灾难持续推进两周后，家庭从"应急模式"进入"磨损模式"。不是一次爆炸，而是持续的重压。

**核心事件线**：
1. **水涨**：一楼逐步被淹 → 生活压缩到二楼 → 最终失去一楼
2. **粮尽**：余量→不足→配给→饥饿→不得不对邻居伸手
3. **家裂**：小摩擦→沉默→爆发→和解或加深裂痕
4. **邻居**：老张再次出现→求助→共同生存→背叛或互助的终局
5. **信息战**：收音机给错误消息→玩家是否信→后果延迟浮现
6. **孩子的画**：小孩子每天画一张画，画的内容反映家庭状态

**关键设计**：第 4~6 天的选项决定第 14~16 天的结果。第 7 天的收音机陷阱是"信息不可靠"的第一次正式落地。

---

| 角色 | 性格 | 说话风格 |
|---|---|---|
| **老人** | 经历过洪水，沉着但身体不好 | 短句，用"当年……"开头，偶尔插一句冷幽默 |
| **伴侣** | 重感情，把家庭安全放在第一位 | 长句，会反问玩家，在意公平 |
| **大孩子** | 聪明，会用手机查东西，话变少了 | 关键字式，像在发消息 |
| **小孩子** | 敏感，不会表达，画代替说话 | 句子短，常答非所问 |

# 暴雨100天 · 设计讨论总结

## 零、你的提问

> 这些问题本身就是设计方向的骨架。按对话顺序排列。

**Q1** 你认为接下来这个游戏应该如何发展。氛围感在哪。列出目前游戏存在的几大痛点。

**Q2** 怎样的文字才能够吸引玩家留住人，还是说靠的其实不是文字哦是场景事件。如果是这样那又该怎么做呢。

**Q3** 先做个 15 天内的循环。几乎所有事件都在这 15 天之内拿到结果。文字完全设计，每个人说的话、对应的选项、以及导致的结果。

**Q4** 这老人这么快就倒了吗？我不希望有老人用药的这个设定。你先把能写的事件都给我列出来让我来选。你只列大概的，细写的我选了之后你再写。

**Q5** 你参考一下六十秒的那些事件设定。我觉得你这些事件都有水分。你觉得问题出在哪。

**Q6** 我觉得像什么精神和家庭气氛这种东西，不要做得太细。以及你把每一个事件做了或不做会发生什么结果都告诉我吧，能不能列树状图。选项可以有一些是各有各的代价，有些就是有好有坏的，但是不能太明显，也不能太莫名其妙不知所云。我觉得可能你得先把所有机制都想明白。

**Q7** 供电机制。洗衣服的机制？潮湿程度的影响。疾病的影响？压抑的影响。从现实角度来看，一百天的暴雨会带来什么麻烦。

**Q8** 事件的设定有什么事件是每天都可以做的。比如查看水龙头、查看食品是否变质、查看供电系统等等。你考虑一下什么是需要的什么是不需要的。

**Q9** 反思一个问题——玩家真的有必要在现有的地图里面移动吗。为什么要移动呢。这和直接做成选项让玩家一个一个选有什么区别。如果他能够提高氛围感，那这种氛围感应该如何体现和加强呢。世界需要关联玩家的生存。

**Q10** 家具损坏了到底对玩家又有什么影响呢。

**Q11** 目前这五个人的角色有什么特点呢。如果不同的人外出会带来什么样不同的结果。每个人有什么样独特的人际网。比如说小孩子认识谁，大孩子认识谁，那么就有可能会有谁来找他。他们又是什么性格呢。

**Q12** 我们游戏的一大重点是不是需要放在街区上。那么街区上是不是应该有其他建筑。应该有哪些建筑呢。这些应该跟剧情相适应。

**Q13** 根据先拓展再删除的原则，考虑街区布局和剧情设计，以及出门的节奏——隔多少天才有事件，事件连续几天都有事件，以及考虑下不下雨、大雨对外出事件的影响。

**Q14** 你觉得我们这个游戏的随机性体现在哪。同时考虑制作难度和必要性。

**Q15** 湿度系统的存在价值还不是很大，能不能拓展一下它的功能。不要盲目拓展，哪些事对玩家玩游戏有用。

**Q16** 现在这个时间设计只是几点几点的，看起来割裂感非常强，一下子就跳，从上午八点半跳到下午两点半。要不改成用几分钟的时间流动来展示一天的时间流动，就像我的世界之类的游戏一样。我觉得这样给玩家的紧迫感会更加直接。当然也要添加跳过多余时间的功能。

**Q17** 我觉得有些选项设定的因果感又太强了。比如说第一天房屋检查哪里没检查，到时候就一定漏水。我认为这不是很好。

**Q18** 总结一下前几次聊天吧。还有就是周围环境的细微变化如何体现你这个世界正在变坏。玩家在家里在阳台上就能看到哪些变化。

**Q19** 我觉得我们需要加入一个手机方便获取社区内容，和邻居对话等。

## 一、氛围与文字

- 留人的不是文字，是「玩家做出的判断被世界回应」。文字只把这个回路说清楚。
- 灰盒画面逼玩家用想象填补——空间本身说话比对话框强十倍。
- 用「空间发现」替代弹窗：玩家走进厨房拧开水龙头出来铁锈水——自己发现，不是 NPC 告诉。
- 家庭关系碎片散落在空间里：伴侣在不该抽烟的地方抽烟、老人把药推到桌子另一头——玩家撞见，比任何数值下降都致命。

## 二、角色设计

| 角色 | 功能 | 专属人际网 |
|---|---|---|
| 玩家 | 决策中心、通用行动者 | — |
| 伴侣 | 稳妥外出、社区情报（登记处同事、超市老板妻子） | 社区中心、超市 |
| 大孩子 | 高风险外出、同龄人情报（同学、体育老师） | 学校、同学家 |
| 小孩子 | 被动情报（在家发现别人发现不了的）、家庭压力的镜子 | 幼儿园老师（不实装地点，仅在对话） |
| 老人 | 固定情报源（历史/建筑/天气判断）、老街坊来访的情感事件 | 老街坊家 |

**不给老人用药设定。** 他和其他成员一样受饿和潮影响。功能是经验和判断。

**不同人外出 → 不同收获。** 伴侣稳妥但拿得少。大孩子可能多跑一条街带回惊喜，也可能惹祸。老人不出门，但他说的旧建筑位置能避免你进入危房。

## 三、核心机制

### 机制必须优先于事件
先想清系统，再设计事件。事件触发 = 系统阈值到了，不是「该有剧情了」。

### 供电
正常 → 不稳定 → 停电 → 永久停电。冰箱失温 → 生鲜 3 天后变质。无灯 → 天黑后不能做事。无充电 → 手机逐步关机。

### 供水
正常 → 低压 → 变黄 → 停水。停水后只能靠储备水 + 阳台接雨水（不可饮用）。

### 湿度与霉菌
每个房间独立湿度等级 0-4。湿度 ≥ 2 → 被褥发潮（睡不好）。湿度 ≥ 3 → 霉斑可见（擦掉消耗体力，不擦房间报废）。湿度 ≥ 2 区域存放干货 → 加速变质。
**核心设计：湿度 = 可用面积在缩小。不是扣血光环。**

### 食物
生鲜（停电后 1-2 天变质）vs 干货（受潮后发霉）vs 罐头（不坏）。每人每天 1 份。缺粮 3 天 → 健康衰减。缺粮 7 天 → 死亡。

### 疾病
不做「概率得病」。风险因子累积（受寒、不洁饮水、食物变质、营养不良、污水接触）→ 达到阈值必然触发。类型取决于主导因子。

### 污水与厕所
马桶反灌 → 一楼厕所无法使用 → 如果不封堵 → 臭味在全层扩散 → 二楼也可能无法用 → 卫生全面崩溃。

### 房屋结构
漏水、渗水、窗户胶条老化、楼梯泡水。不问你有没有检查——时间到了必然坏。你的选择不是「漏不漏」，是「漏的时候拿什么接」。

## 四、随机性的尺度

只做三类，制作成本低：

| 类型 | 怎么做 | 为什么不做更多 |
|---|---|---|
| 天气窗口的浮动 | 窗口结束时间 ±1 天 | — |
| 地点物资轻量刷新 | 固定清单 + 1-2 格随机物品 | 外出收获不用完全一样 |
| 霉变概率 | 湿度到了，不是 100% 当天坏。但有文字预警 | 发霉确实有时间差 |
| 不做：疾病概率 | — | 概率生病 = 玩家反思不了选择 |
| 不做：NPC 行为随机 | — | 老张必须可靠，否则「信谁」没意义 |

**核心：紧张感不来自骰子，来自多条矛盾信息同时出现。**

## 五、事件设计原则

### 旧逻辑（已删除）
- ✕ 「你没做检查 X → 第 N 天出事」
- ✕ 散文式情绪渲染（伴侣抽烟、孩子画画、老人回忆录）
- ✕ 因果强绑定（第一天没清排水口一定倒灌）
- ✕ morale 数值系统 + 「家庭气氛」软指标
- ✕ 每件事几大段文字描述

### 新逻辑
- ✓ 事件触发 = 系统阈值。雨下了 6 天 → 屋顶必漏。跟检查无关。
- ✓ 文字最多 3 句。选项 2-3 个，各有代价，不存在「好选择」。
- ✓ 家人的情绪不设数值 → 用行为表达（不吃饭、不跟你说话、摔门）。
- ✓ 死亡存在。不会突然——前面必然有征兆。
- ✓ 每天 2-3 件事。没有连续三天密集事件。

## 六、时间系统

从「上午 8:30 → 下午 4:00」的幻灯片方式改为**流动时钟**。

每分钟在走，每个动作消耗真实分钟数。HUD 上显示 HH:MM。天暗了没有电池就不能做事。出门前要算往返时间。站桩不动时按一个键快进到下一个事件。

## 七、从阳台上看到的世界变化

D1-D15 每天窗外视觉变化。从「对面墙根湿了」到「一只不是我们家的拖鞋漂过去」到「水面上多了一块不是老张的泡沫板」。建立基准线 → 打破基准线。不需要文字解释。

## 八、街区与地点（9 个）

| 地点 | 绑定角色 | 核心功能 |
|---|---|---|
| 自己家 | 全部 | 基地、防守 |
| 老张家 | 玩家 | 独立信息源、互相支援 |
| 社区超市 | 你+伴侣 | 物资、店主情报 |
| 药店 | 通用 | 药品 |
| 社区中心 | 伴侣 | 物资发放 + 同事的清单 |
| 同学家 | 大孩子 | 大孩子独立剧情线 |
| 学校 | 大孩子 | 最多幸存者聚集 + 真相 |
| 老街坊家 | 老人 | 情感锚点 + 旧建筑位置 |
| 加油站 | 通用 | 燃料、杂物 |

**地点有主次。** 不是所有地点都能进——有些仅在对话中存在（幼儿园），有些纯装饰（街灯、其他民宅）。

## 九、15 天节奏

2-3 天暴雨（不能出门）→ 1 天窗口（能出门）。D7（收音机 vs 老张）和 D11（是否出门、谁出门）是两大决策高峰。D14 是结果日。D15 收束。

## 十、手机系统

### 硬件状态

手机有**电量**和**信号**两个独立轴。

| 天数 | 电量 | 信号 |
|---|---|---|
| 暴雨前 | 满 | 满格 |
| D1-2 | 正常消耗 | 满格 |
| D3-4 | 如果无充电 → 30-50% | 一格 |
| D5 | 如果还无充电 → 关机 | 无服务 |
| D5+ | 有充电宝可充一次（充到 40%） | 充了也没信号 |

### 信息结构

按天数索引的文本列表。不是实时接收——是翻看**离线缓存里已收到的旧消息**，每天解锁几条新的。

#### 暴雨前

| 来源 | 内容 |
|---|---|
| 社区群 | 物业通知：暴雨预警，请清理阳台物品、检查排水口 |
| 超市老板 | 今天最后一批进货，晚上关门 |
| 大孩子的同学 | 发了定位：我家的位置，到时候如果没信号就来这里找我 |
| 伴侣的同事 | 问伴侣：登记低洼住户时有没有注意到 XX 号那家独居老人 |
| 学校 | 通知：明天正常上课，如有变动另行通知 |
| 老张 | 对你说：我家车库有点不太对，你帮我看看？（如果帮过他） |

#### D1-D3

| 来源 | 内容 |
|---|---|
| 社区群 | 一楼开始进水的住户请报一下 |
| 超市老板 | 超市大门被水冲开了 |
| 学校 | 所有学生不要来校，已在学校的留在教室等候家长 |
| 同学 | 最后一条：我在学校，他们说会有人来接。没来。 |
| 伴侣的同事 | 社区中心一楼淹了。册子在二楼第三个柜子最上面。之后如果联系不上我——你知道在哪。 |

#### D4-D6（信号开始断）

| 来源 | 内容 |
|---|---|
| 社区群 | 住户 A：我家二楼还有地方，谁需要？→（3 小时后）进水了。不用来了。 |
| 体育老师 | 我目前在学校体育馆，12 个学生 + 2 个家长。有食物和水。知道的人互相转告 |
| 老张 | 我在屋顶上。你还在吗 |

#### D7（闪回、然后彻底黑）

| 来源 | 内容 |
|---|---|
| 未知号码 | 收音机里听到的救援广播我们也听到了。但没看到船。我不是你附近的人，我离你两条街。 |

## 十二、本轮继续讨论的问题

> 以下内容继续采用“玩家的问题 → 当前讨论答案”的方式记录。这里只追加新内容，不覆盖前面的讨论。

**Q20** 前 15 天的剧情应该怎样整理？要求在这 15 天内闭环。

**当前答案**：前 15 天作为一个完整的第一章。凡是在第 1—15 天提出的具体剧情问题，都必须在第 15 天结束前得到回答；选择造成的资源、关系和房屋状态可以继续影响后续，但不能把事件答案拖到第 16 天以后。第 15 天可以保留“暴雨还会继续”这一长期压力，但不能留下“外出的人是否回来、救援是否会到、老张是否还活着、重要决定有什么结果”等未回答问题。第 14 天集中回收结果，第 15 天只做盘点、人物反馈和章节收束，不再开启新的短期悬念。

**Q21** 原来列出的设计问题，哪些真正解决了，哪些只是写过答案但没有落实？

**当前答案**：已经基本确定的方向包括：场景反馈比长文字重要；灾害由时间和环境阈值触发，不能由早期检查强绑定；湿度的价值是压缩可用生活空间；随机性只保留天气窗口、少量物资和霉变浮动；家庭压力主要通过行为表现。仍需解决或统一的内容包括：`morale` 是否彻底删除、老人用药剧情的清理、时间系统、每日动作、移动价值、街区开放范围、手机交互和第 15 天具体闭环。后续不能再把“文档里出现过一个方案”当成“已经完成设计”。

**Q22** 时间自然流动以后，上午和下午是否分别使用倒计时？上午结束后是否需要玩家确认进入下午？

**当前答案**：整天只使用一条连续时钟，不拆成上午、下午两个回合。中午到达时不暂停、不要求确认，只自然改变光线、天气、NPC 位置、事件开放条件和 HUD 时段。只有夜间结算和进入新一天需要玩家确认。第一版暂定一天约 15 分钟现实时间，从 08:00 连续运行到 20:00；具体长度必须通过实玩测试调整。

**Q23** 已经有自然流动的时间后，玩家做事情是否还需要额外扣除若干游戏时间？如果玩家操作足够快，是否应该允许完成更多事情？

**当前答案**：不再使用“选择行动后直接跳过 30 分钟或 1 小时”的抽象扣时。所有行动都在同一条时钟上真实进行：查看、走路、取放、搬运、修补和整理本身需要操作过程，时间在过程中自然流逝。熟悉房屋布局、提前准备工具、少走弯路和安排并行任务的玩家，应该能在一天内完成更多事情。无法全部解决的问题主要来自同时发生的冲突、材料不足、天气窗口和外出风险，而不是强制行动点。

**Q24** 哪些界面应该暂停时间？怎样在紧迫感与思考空间之间取得平衡？

**当前答案**：玩家打开自身背包时暂停时间，让玩家能够检查携带物并规划下一步；打开冰箱、食品柜等世界容器并整理物资时，时间正常流动，因为这是在世界中实际执行工作。剧情对话和重要选择暂停，避免阅读速度影响结果。平衡优先照顾第一次游玩的玩家：重要危险必须提前给出征兆，错过一次检查通常只失去信息或让问题逐步恶化，不能因为菜单操作慢就立即造成严重惩罚。家庭状态、手机、地图等其他界面是否暂停，仍需单独确认。

**Q25** 为了操作方便，是否需要制作一个类似说明书的东西，告诉玩家还能去哪些地方以及当前主要目标？

**当前答案**：需要，但不建议做成一次性塞给玩家的大段传统说明书。更合适的是一个可随时打开的“家庭生存手册 / 家庭记事本”，同时承担教学、导航和信息整理功能。HUD 始终只显示当前最重要的目标；手册保存详细信息，并允许玩家暂停下来思考。

手册第一版建议包含：

- **当前目标**：明确写出地点、对象和动作，例如“去一楼厨房检查水龙头”。
- **可去地点**：显示已经知道的房间和街区地点、当前位置、开放条件及当前是否安全；尚未发现的地点不提前剧透。
- **家庭与房屋记录**：记录玩家已经确认的供水、供电、积水、潮湿和家庭成员状态；没有检查过的信息显示为“未知”，不能自动提供答案。
- **线索与消息**：整理收音机、手机、邻居和环境中已经获得的信息，同时保留信息来源，方便玩家判断可信度。
- **操作说明**：保存按键、容器操作、快捷移动、时间暂停规则和常用动作说明。

手册的作用是帮助玩家记忆和规划，不替玩家做判断。它只能记录玩家已经知道的事实，不能显示隐藏后果、正确选项或未来事件。打开手册是否暂停时间暂定为“暂停”，因为它属于思考界面；这一点可在实际测试后再确认。

## 十三、本轮已经确定的时间系统

1. 每天使用一条连续时钟，中午不进行回合式确认。
2. 时间在移动和世界操作中自然流动，不使用额外的抽象行动扣时。
3. 玩家效率、路线熟悉度和提前准备会真实增加一天内能完成的事情。
4. 自身背包暂停；冰箱、食品柜等世界容器整理时不暂停。
5. 剧情对话和重要选择暂停，避免阅读速度成为惩罚。
6. 初始测试值为每天约 15 分钟现实时间，最终数值以新玩家和熟练玩家的实玩结果为准。
7. 时间压力应该迫使玩家安排优先级，但必须保留安全的思考空间。

## 十四、2026-07-22 最新决定（覆盖此前冲突方案）

> 本节只追加，不修改前文。前文是讨论历史；凡与本节冲突，以本节和当前PRD、机制总表为准。

**Q26** 暴雨第一天的水龙头、冰箱、窗沿渗水和睡觉事件，还缺哪些能直接做进游戏的规则？

**当前答案**：水龙头不能只写“储备水+10L”，必须有可重复容器、水质和供水状态；冰箱必须按食物份数、制冷状态和各自保质期记录；窗沿渗水要绑定具体客厅窗户、消耗2卷胶带封堵，并允许玩家没发现但后果继续发展；睡觉不强制完成事件，只结算玩家发现的事件和已经真实发生的后果。

**Q27** 供水、供电应该在哪几天中断，分别影响什么？

**当前答案**：暴雨第1—3天市电正常且自来水可直饮；第4—5天外部电网中断，水龙头仍出不能直饮的自来水原水；第6天起水龙头完全无水。停电影响冰箱和设备，不先制作固定照明，地图保持可见。电池与充电宝不能带动电热水壶和电饭锅。第1—2天的局部配电故障可用基础工具箱修复，但外部电网彻底中断后无法靠修配电箱恢复。

**Q28** 水应该如何分类，接水次数和水桶怎样限制？

**当前答案**：水分为直饮水、自来水原水、雨水和预处理雨水；厕所倒灌等真正污水不进入饮用水转化。家中初始自带一个15L可重复水桶。接水和净水不直接限制点击次数，限制来自空容器、容量、供水状态、原水、目标容器、滤芯与设备单日处理量。自来水原水可以烧开；雨水必须先预处理，再经过专用净水器。

**Q29** 为什么需要两种净水器和滤芯？

**当前答案**：便携式手压净水器体积小、处理量低，使用便携滤芯；多级重力净水器体积大、处理量高，使用多级滤芯组。两类滤芯互不兼容，避免所有滤芯都被投入同一个最优设备。净水器获得时自带一枚滤芯，后续滤芯可通过事件获得。

**Q30** 五个人的吃喝是否一起分，食物怎么变质？

**当前答案**：中午为五名角色分别选择食物和1L饮水，每人每天只有一次进食和一次饮水机会，确认前可以反复调整。食物按剩余份数记录。无制冷后生肉和鲜牛奶2天、蔬菜3天、鸡蛋6天；查看时显示新鲜或倒计时。变质食物不会立刻删除，而会逐渐减少份数，冒险食用会损失健康和精神。普通食物的精神恢复最多到80，巧克力和鲜牛奶可以超过80。

**Q31** 是否加入酒和香烟？

**当前答案**：加入并按剩余次数记录。酒可供成年人使用，恢复少量饥饿、口渴和较多精神，但损失健康；香烟只允许父亲和老人使用，恢复精神但损失健康。二者的精神恢复都可以超过80。

**Q32** 厕所为什么要存在，角色如何上厕所？

**当前答案**：每人每日基础如厕需求+15，进食+35、饮水+45，并有角色差异；一次占用15游戏分钟。马桶水箱12L，暴雨第6天起每次冲洗2L。水不足会产生未冲洗/脏污，累计3次堵塞；脏污用4L非饮用水清理，堵塞需基础工具箱和6L非饮用水疏通。四名NPC达到100后自动排队并走到二楼卫生间；父亲由玩家走到厕所主动使用，期间短暂不能移动。卫生间用半透明顶盖表现私密空间，不让人物凭空消失。

**Q33** 如果所有当天事件都在早晨一次列出，或者玩家没靠近NPC就错过重要剧情，应该怎么办？

**当前答案**：早晨只播报公共天气和供应状态；具体事件必须靠近地点或人物后查看。可选事件允许错过，世界后果继续发展。真正必须传达的信息不能靠碰运气，应通过HUD点名地点和人物、让NPC主动靠近，或在截止时间前主动提醒。未发现原事件不进当天总结，但后果发生后进入后果当天总结。

**Q34** 当前要保留哪些剧情？

**当前答案**：此前的邻居、接人、重复购物、车库、广播真假和第8—15天具体剧情全部作废。当前只保留第0天准备和暴雨第1—7天机制纵切：第1天窗沿渗水在第2天闭环，第2天局部冰箱回路故障可修，第3天为最后正常水电日，第4天停电并出现自来水原水，第5天为最后管道水日，第6天彻底停水并启动冲厕耗水，第7天验证完整室内循环。第8—15天暂时留空，后续具体剧情必须先讨论确认再写入。

**Q35** 三个结局方向如何保留？

**当前答案**：保留军方救援、造船离开、坚持到暴雨结束三条方向，预计在暴雨第80—100天收束。军方路线需要提前获得可靠信息并面对名额或冲突；造船路线需要工具、指南、材料和成船；坚守路线需要维持家庭与房屋到百日结束。前七天只预留状态，不提前发放结局钥匙。

**Q36** 最终时间系统和说明书如何调整？

**当前答案**：仍然是一条连续时钟，但测试值改为07:00—23:00、现实1秒对应游戏2分钟，一天约8分钟。12:00后强制打开逐人配给界面，确认后继续同一条时钟，不重新计时。自身背包、说明书和剧情对话暂停；冰箱、食品柜与水容器整理不暂停。说明书列出当前目标、可去地点、每日循环和玩家已经检查确认的环境状态。

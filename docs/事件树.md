# 暴雨第 4~18 天 · 事件树状图

> 原则：每件事都因系统状态触发，不是"到了该有剧情所以写一段"。每件事有明确资源后果。文字控制在 3 句以内。不存在"陪孩子画画"这种不跟系统对话的选项。

---

## 第 4 天

### E4.1 厨房水龙头

触发：暴雨第 4 天上午。供水系统进入「变黄」状态，首次发现。

正文：水龙头拧开，先是噗噗喷气，然后流出黄水。水槽里昨天的筷子还架在碗上。

```
├── [ 接几桶 ]
│   └── 储备水 +3L（不可饮用）
│       但有代价：厨房地面又湿一片，该房间湿度 +1
│       如果厨房湿度达到 3，墙角开始起皮 → 老人关节不适
│
└── [ 关一楼水阀 ]
    └── 一楼停水。以后所有卫生间用水只能从阳台接雨水。
        好处：不再漏水到地板。
        代价：冲厕所要用下雨接的水。每天消耗 2L 储备水用于冲厕。
```

**如果玩家什么也不做**：黄水继续滴滴答答，厨房地面持续变湿。每天厨房湿度 +1。

---

### E4.2 一楼地面反潮

触发：第 4 天下午。一楼地面踩出水印，沙发腿是湿的。

正文：客厅地面走一步印一个鞋印。电视柜后面墙根颜色变深。

```
├── [ 搬东西上二楼 ]
│   └── 被褥、电器、药物搬到二楼。
│       代价：全家体力消耗（玩家健康 -2，伴侣健康 -1）
│       好处：东西不会泡烂。一楼可以放弃。
│       老人说：「当年也是从一楼搬到二楼过的。」
│
└── [ 只搬电器和药 ]
    └── 被褥还在楼下。第 5 天早上发现被子湿了。
        玩家健康 -1（夜里冷），小孩受凉（感冒风险 +1）
```

**如果什么也不做**：第 5 天早上所有一楼物品泡水 50%，随机损毁。

## 第 5 天

### E5.1 冰箱里的东西

触发：停电第 2 天，冰箱内部温度已不足以保鲜。

正文：打开冰箱门，一股酸味。买回来的菜叶子发黄，肉的颜色不对了。

```
├── [ 把还能吃的做成热食 ]
│   └── 消耗 1L 水和 20 分钟。抢救出 3 份熟食（保质期 +1 天）。
│       坏掉的部分扔掉（损失 2 份生鲜）。
│
└── [ 扔掉，不冒险 ]
    └── 所有生鲜全部丢弃（损失 5 份生鲜）。
        但节省了水，且没有人吃坏肚子。
```

**如果什么也不做**：家人可能吃到变质食物 → 随机 1 人食物中毒。

---

### E5.2 大孩子的充电宝没电了

触发：停电后第 1-2 天，手机电量耗尽。

正文：大孩子翻遍了抽屉。充电宝还剩最后一格。「手机黑了。以后没人能打电话了。」

```
├── [ 把最后一个备用电池给他 ]
│   └── 消耗备用电池 1。大孩子手机多撑 2 天。
│       好处：第 7 天手机还能收离线消息（线索）。
│       代价：少了一个备用电源，手电筒或收音机少一次使用机会。
│
└── [ 让他省着用 ]
    └── 大孩子把手机放进口袋，没说什么。
        第 7 天不会触发手机离线消息事件。
        大孩子不说话的时间变长（压力 +1）。
```

## 第 6 天

### E6.1 食物盘点

触发：第 6 天上午。与 E5.1 的结果衔接。

正文：你把所有食物从柜子里搬出来。米袋瘪了大半。罐头没动，但靠罐头撑不了几天。

```
├── [ 定量分配——每人每天固定份量 ]
│   └── 食物消耗从 5 份/天 降到 4 份/天。
│       代价：所有人饥饿感上升。老人和小孩健康 -1/天。
│       好处：食物多撑 2 天。有明确的数字可以告诉每个人。
│
└── [ 不配给——吃多少拿多少 ]
    └── 食物消耗维持 5 份/天。
        第 10 天食物将率先见底。
        但老人不会马上饿到（前 5 天不会触发老人拒绝进食事件）。
```

---

### E6.2 天花板漏水

触发：第 6 天。屋顶某处积水渗透。

正文：二楼卧室墙角多了一道水印，从天花板一直流到踢脚线。用手按上去是软的。

```
├── [ 用胶带临时补 ]
│   └── 消耗胶带 1 卷。该房间湿度不再额外上升。
│       代价：治标。修补只能管 3 天，之后会再次裂开。
│
├── [ 放个桶接着 ]
│   └── 该房间湿度每天 +1。水滴进桶的声音持续响。
│       桶要定期倒。如果忘了倒（扣 1 次行动），水溢到地板上。
│
└── [ 不理 ]
    └── 该房间湿度每天 +2。第 9 天房间进入「发霉」等级。
        被褥、储物全部受潮。住在该房间的成员每天健康 -2。
```

## 第 7 天

### E7.1 收音机的信号

触发：第 7 天清晨。如果还有电池或收音机还能运作。

正文：收音机突然发出一串清楚的播报：「……请低洼住户留在室内等待救援……已有救援队沿排水河方向……保持可见标记……」

```
├── [ 信了——在窗外挂显眼的东西 ]
│   └── 全家士气回暖。挂出去的红布或雨衣在外面淋着。
│       第 14 天触发结果事件：外面没有救援船来。
│       如果信了但第 14 天落空 → 可信信息源 -1，家人对你的判断产生质疑。
│
├── [ 不信——但记住播报内容 ]
│   └── 红布折起来放窗边。你告诉家人「先别指望」。
│       家人无士气变化。
│       第 14 天不会有落空打击，但如果真有救援来（取决于老张线），你可能错过。
│
└── [ 不告诉家人 ]
    └── 你把收音机音量关了。伴侣问怎么了——「没事。」
        如果第 7 天你瞒了家人，第 9 天伴侣发现窗台上的红布 → 关系紧张。
```

---

### E7.2 隔壁老张

触发：第 7 天中午。老张出现在自家屋顶上。

正文：老张在屋顶上搬东西。看到你，他指了指排水河方向，反复摇头。没有救援。他在屋顶上看了七天，没看到一条船。

```
├── [ 跟他喊话——告诉他收音机说了什么 ]
│   └── 老张愣了一会，然后比了个手势：「那我也挂个东西。」
│       老张家屋顶挂了一件黄雨衣。
│       如果第 14 天收音机落空，老张不怪你。
│
├── [ 信他的——收音机可能不准 ]
│   └── 你判断：一个人站在屋顶上看了七天，比一条断续广播更可靠。
│       第 14 天触发：老张在远处立交桥上看到有人放防水桶。
│       这条线索可能帮你找到食物或药。
│
└── [ 不理他 ]
    └── 老张看了你一眼，转回去了。
        第 10 天触发：老张仍然在屋顶，但他不再主动跟你交流。
```

## 第 8 天

### E8.1 有人病了

触发：第 8 天。如果某个成员有 ≥ 2 个风险因子持续 ≥ 2 天（受寒、潮湿、营养不良等）。

正文：（受寒者）从昨天晚上开始咳嗽，今早额头烫手。药箱里的感冒药只剩一板了。老人/小孩蜷在被子里没起来。

```
├── [ 给药 ]
│   └── 消耗感冒药 3 粒。病情止住，3 天后痊愈。
│       代价：如果后面再有人生病，只剩 9 粒。
│
├── [ 不给药——用物理降温 ]
│   └── 消耗玩家健康 -2（守夜）。病人每天健康 -3，持续 3 天后自愈。
│       代价：这 3 天内病人无法帮忙（不消耗他的行动力但也不产出）。
│       如果这 3 天内又添新病，可能恶化成肺炎。
│
└── [ 灌热水、加被子 ]
    └── 消耗储备水 1L。病人健康 -2/天，持续 2 天。有 40% 概率自愈，60% 概率加重。
```

---

### E8.2 墙上的霉斑

触发：某房间湿度达到 3，首次可见霉斑。

正文：客厅墙角出现一小片灰绿色的霉斑。靠近能闻到土腥味。

```
├── [ 擦掉 ]
│   └── 玩家健康 -1。该房间湿度 -2。
│       但如果不解决源头（漏水/通风），3 天后会再次出现。
│
└── [ 不管 ]
    └── 霉斑每天扩大。该房间 3 天后进入「严重霉变」。
        住在里面的人每天健康 -3。被褥衣物逐步损毁。
```

## 第 9 天

### E9.1 伴侣发现了收音机的事

触发：仅当 E7.1 选了「不告诉家人」。第 9 天上午。

正文：伴侣在窗台收水桶时看到折着的红布。「收音机是不是说过什么。」不是问句。

```
├── [ 说实话 ]
│   └── 「对不起。我怕你们抱太大希望。」
│       伴侣说「下次告诉我」。关系不变。
│
└── [ 继续瞒 ]
    └── 伴侣把布放回去，没再问。但看你的眼神变了。
        从此伴侣的重大决定不再先跟你商量。
```

---

### E9.2 食物的味道不对

触发：第 9 天，如果还有干货存放在湿度 ≥ 2 的区域。

正文：打开米袋，有股闷味。一两颗米粒上带绿点。

```
├── [ 挑出来继续吃 ]
│   └── 保留 70% 食物。随机 1 人肚子不适（健康 -2）。
│       小孩和老人更容易中招。
│
└── [ 扔掉 ]
    └── 损失一批干货（约 3-4 份食物）。
        但没人吃坏。伴侣说「可惜了。」
```

## 第 10 天

### E10.1 水到第三级台阶

触发：一楼水位累计上升（取决于降雨强度 + 是否舀水）。

正文：水已经漫上第三级楼梯台阶。一楼客厅的水没过小腿肚。沙发浮起来了。

```
├── [ 测水位 ]
│   └── 你用绳子打了结固定在楼梯栏杆上。
│       以后每天能看到水位变化——知道是涨是退。
│       大孩子帮你弄完，说「至少知道什么时候淹到这层。」
│
└── [ 在楼梯口堆箱子当坝 ]
    └── 延缓水位上涨 1 天。
        但箱子之后都湿了，里面如果有东西 → 损毁。
        老人说：「当年修的坝也不一定能挡住。」
```

---

### E10.2 老张还在屋顶上

触发：仅当 E7.2 选了「不理他」。第 10 天。

正文：隔壁屋顶上，老张还坐在那里。旁边多了一个倒扣的塑料箱当桌子。

```
├── [ 这次跟他挥了手 ]
│   └── 老张愣了一下，也挥了。然后比划：三条街外有人发东西。
│
└── [ 拉上窗帘 ]
    └── 伴侣看着你拉窗帘的动作。以后伴侣不再建议你帮邻居。
```

## 第 11 天

### E11.1 老人 / 小孩起不来了

触发：如果连续 4 天没吃饱，或房间湿度 ≥ 3。

正文：老人没起床。呼吸浅，嘴唇发白。伴侣蹲在旁边抬头看你，那个眼神你是第一次见到。

```
├── [ 把存粮全都拿出来 ]
│   └── 今天让全家吃饱。
│       老人健康 +3。但食物消耗翻倍（今天用 8 份）。
│       你知道这么做明天会更难。
│
├── [ 问老张有没有多余的食物 ]
│   └── 你到阳台上喊老张。他想了想，扔了一包过来。
│       里面是半只咸鸭蛋、两片饼干。老人吃了，健康 +2。
│       但老张自己也在饿。下次他未必还能给。
│
└── [ 不做特殊处理——按定量继续 ]
    └── 老人今天继续按定量吃。
        健康 -3。伴侣今天看你的眼神变了。
```

---

### E11.2 大孩子说「我要出去」

触发：第 11 天。如果大孩子压力 ≥ 中，且外面有物资线索。

正文：大孩子在阳台站了很久。回屋之后说：「老张说桥那边在发东西。我去。」你没来得及拦——他已经把防水袋翻出来了。

```
├── [ 让他去 ]
│   └── 大孩子出门。第 12 天晚上回来。
│       健康 -5，但带回来 3 包压缩饼干 + 1 板药 + 外部消息。
│       伴侣全程站在窗口看，指甲在窗框上掐出了印。
│
├── [ 你去，让他留下 ]
│   └── 你出去。第 12 天晚上回来。玩家健康 -8。
│       带回来的物资同上。
│       代价：你不在的时候家里没人统筹，家人消耗可能失控。
│
└── [ 谁也不去 ]
    └── 大孩子摔门进了房间。不出门，但也不理你。
        食物不增加，靠现有的撑。
```

## 第 12 天

### E12.1 出去的人回来了

触发：仅当第 11 天有人出门。

正文：门被推开。出去的人满身泥回来。把几样东西放在桌上：压缩饼干、半盒药。然后靠着墙滑坐到地上。

```
├── [ 先给他擦干净，倒水 ]
│   └── 回来的人健康 +2。伴侣默默地拧毛巾。
│
└── [ 先看带回来什么 ]
    └── 回来的人健康不变。但看到你第一时间检查物资，他/她没说什么。
```

---

### E12.2 伴侣说「我不确定还能撑几天」

触发：如果过去几天粮食紧张 + 伴侣压力 ≥ 中。

正文：伴侣坐在床边，对着窗外说：「你算过吗。我们还能撑几天。」

```
├── [ 把数字告诉她/他 ]
│   └── 「定量分还能撑 4 天。之后没有。」伴侣沉默。然后说「知道了。」
│       知道数字比不知道好。但你看到她在重新排列柜子里的食物——从自己能拿到的位置放到了你更容易拿到的位置。
│
└── [ 说「会有的」 ]
    └── 伴侣没有追问。但在她/他的脑子里，已经不相信你的数字了。
        下一次关于食物的事，伴侣会自己做决定。
```

## 第 13 天

### E13.1 一楼的异味

触发：污水系统进入「反灌」状态。

正文：楼梯口飘上来一股下水道的味道。楼下的马桶在倒灌。

```
├── [ 下去封住马桶 ]
│   └── 消耗胶带 1 卷 + 塑料袋。一楼马桶封死。
│       房间病菌风险 -1。
│       但你在污水中踩了一脚（污水接触风险 +1，可能感染）。
│
└── [ 不管——反正不用一楼厕所 ]
    └── 臭味持续上涌。二楼居住区域可以闻到。
        所有成员疾病风险 +1。老人和小孩最先不适。
```

---

### E13.2 有人开始不跟家里说话了

触发：某个成员压力 ≥ 重度。

正文：（大孩子/伴侣/老人）从昨天起基本上不说话。不是赌气——是把所有东西吞进去了。你喊他/她吃饭，回答只有「嗯」。

```
├── [ 单独找他谈 ]
│   └── 不谈事情，只坐在旁边。过了很久他/她说了一句话。
│       可能是「第几天了」，可能是「对不起」，也可能什么都不说。但第二天恢复了沟通。
│
└── [ 让他静一静 ]
    └── 他继续沉默。第 15 天之前不会主动跟你说话。
        但行动上还是会配合——只是配合，不是参与。
```

## 第 14 天

### E14.1 收音机的答案

触发：仅当第 7 天信了收音机。

正文：窗外和七天前一模一样。没有船，没有救援服，没有任何人的声音在雨里。

```
├── [ 把那条红布收进来 ]
│   └── 红布淋成灰色。大孩子看着你折布，只说了一句：「收音机不对。」
│       你说「嗯。」然后他把布放进了水盆里——不是扔。
│
└── [ 还挂在那里 ]
    └── 你不肯收。伴侣把它收了。
        「泡了七天了。换一条。」你听不懂这是换话题还是换心态。
```

### E14.2 老张的答案

触发：仅当第 7 天信了老张。

正文：老张用手势指着远处的立交桥。你仔细看——桥上有人在放一排防水桶。密封的米袋。

```
└── 确认：老张说对了。第 7 天的判断在第 14 天得到了印证。
     第 15 天事件中你会考虑是否去取。
```

### E14.3 窗外的光

触发：第 14 天下午。

正文：云头裂了一条缝。一小片灰色没那么灰。你和大孩子同时看到，谁都没说话。过了很久大孩子说：「不是太阳。但也不是雨。」

```
└── 无分支。这是一个「天可能开始变了」的提示。
     第 16 天可能会触发天气转折事件。
```

## 第 15 天

### E15.1 老人说了一句话

触发：如果老人还活着。

正文：老人今天开口说了一句比「嗯」更长的话。「当年水淹到二楼，我跟几个街坊在屋顶上等了九天。船上的人最后来了。但不是你想的那种来了。」


# 暴雨100天：3D房屋样板

这是与冻结的 2D 版本并列的独立 Godot 4.7 项目。本阶段只验证第一人称住宅空间、动线和水位视觉表现，不迁移剧情与事件。

## 建筑标高

- 南侧道路作为 `±0.00`，地面向北侧缓慢升高。
- 车库地面约 `+0.45m`，居住区一楼约 `+0.65m`，不再使用悬空的大型台地。
- 二楼地面约 `+3.65m`，屋顶约 `+6.65m`。
- 车库直接朝南侧道路开门；入户门在车库东侧，楼梯靠墙布置。

## 房屋关系

一楼后排为老人房、卫生间和厨房餐区，前排为低位车库、楼梯/玄关和客厅。车库与住宅之间有内门，厨房与客厅保留宽开口，方便形成家庭活动核心。

二楼后排为青少年房、卫生间、储物过道和儿童房；前排为主卧、楼梯 landing 和家庭活动区。南侧与东侧连接一处 L 形阳台，用于观察道路和水面。

## 操作

- `WASD`：移动
- 鼠标：观察
- `Shift`：加速
- `Space`：跳跃
- `F`：开关手电筒
- `Esc`：释放鼠标
- 数字键 `1—7`：预览从道路薄积水到二楼进水的不同水位
- `R`：回到一楼客厅/玄关出生点

直接用 Godot 打开本目录下的 `project.godot` 即可运行。正式美术、剧情和外出事件不在本灰盒阶段处理。

# 暴雨100天：3D房屋样板

这是与2D版本并列的独立Godot 4.7项目，目前只验证第一人称住宅空间和水位表现，不包含剧情迁移。

## 房屋设定

- 房屋建在高出道路约2米的台地上，前门通过台阶进入。
- 一楼：低位车库、厨房、老人房、卫生间、客餐厅、玄关和楼梯。
- 二楼：主卧、两个孩子的房间、家庭活动区、储物区。
- 平屋顶保留为后期临时观察点或撤离空间，但本轮不制作屋顶玩法。
- 一楼和二楼通过有真实坡度碰撞的楼梯连接。

## 平面关系

一楼从低风险到高风险并不是平均分布：左侧车库拥有独立外门，是最先暴露于积水的空间；老人房贴近卫生间；客餐厅与楼梯连通，承担家庭集合和向二楼搬运物资的功能。

```text
北 / 房屋后侧
┌────────车库────────┬────厨房────┬──老人房──┐
│ 车辆、货架、低位纸箱 │ 食品柜、冰箱 │ 床、药品柜 │
├──────────────────┴────┬─────┴──卫生间┤
│       车库内门          │    客餐厅、楼梯    │
├───────────────────────┴────────────┤
│                   玄关 / 高地前门                 │
└────────────────────────────────────┘
南 / 台阶、边沟、道路
```

二楼的公共活动区围绕楼梯井布置。三个卧室在后排，前侧窗户可以持续观察道路和外部水面，左前角留作逐日增加的家庭储备区。

```text
北 / 房屋后侧
┌────主卧────┬──大孩子房──┬──小孩子房──┐
├──────────┴──────┬───┴────────┤
│  储备箱、临时生活区   │ 家庭活动区、二楼沙发 │
│                       楼梯井                    │
└────────────────────────────────┘
南 / 面向道路的观察窗
```

## 操作

- `WASD`：移动
- 鼠标：观察
- `Shift`：加速
- `Space`：跳跃
- `F`：开关手电筒
- `Esc`：释放鼠标
- 数字键 `1—7`：预览从道路积水到二楼受淹的不同水位
- `R`：回到一楼出生点

直接用Godot打开本目录下的`project.godot`即可运行。

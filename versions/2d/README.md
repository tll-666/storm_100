# 暴雨100天：2D主开发版本

这里保存当前主开发用的 2D 工程。3D 房屋实验版仍保留在 `versions/3d/`，不与本工程共享资源。

- 独立入口：`project.godot`
- 主场景：`scenes/main.tscn`
- 当前主线：前七天剧情与房屋内水位表现验证。
- 可玩地图范围：一楼、二楼、封闭窗边观察区和屋顶信息点；房屋外部只显示黑幕，不制作前院、街道、阳台外缘或其他住宅。
- 车库从可玩地图中移除；外出准备改在一楼玄关完成，外出过程进入独立事件场景。
- 社区超市只作为独立的外出事件场景保留，不代表完整街区地图。
- 室内取消战争迷雾，房间和互动点始终可见；声音、门缝和窗边检查继续承担外部环境反馈。

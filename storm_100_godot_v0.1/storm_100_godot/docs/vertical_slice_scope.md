# 第一阶段纵向切片范围

## 完成边界

完整流程从“暴雨前第3天”开始，到“暴雨第3天夜间结算”结束，预计首次游玩30—50分钟。

## 时间线

| 时间 | 可玩内容 | 主要验证目标 |
|---|---|---|
| 暴雨前第3天 | 家庭需求、房屋检查、第一次普通购物 | 家庭介绍、价格和容量 |
| 暴雨前第2天 | 短过渡、新闻和环境暗示 | 节奏和伏笔 |
| 暴雨前第1天 | 降雨、接人、第二次购物 | 汽车、路线和选择回调 |
| 暴雨第1天 | 红色预警、最后购物、回家 | 商店变化和天气升级 |
| 暴雨第1夜 | 第一次家庭结算 | 食物、水、电力消耗 |
| 暴雨第2天 | 短暂停电 | 电池、充电宝、收音机反馈 |
| 暴雨第3天 | 车库渗水 | 水桶、胶带和物资转移反馈 |

## 第一阶段分支预算

- 主要分支1：先接伴侣或先接大孩子。
- 主要分支2：走安全主干道或排水河近路。
- 主要分支3：车库渗水时封堵、接水或转移物资。
- 条件反馈：电池、充电宝、饮用水、普通食品和此前对话承诺。
- 不制作永久分裂的平行主线，所有分支在阶段节点重新汇合。

## 系统边界

第一阶段只维护家庭共享食物、饮用水和电力。人物使用“正常、疲劳、淋湿、不满”等状态标签，不建立多条公开数值好感度。选择影响通过隐藏标记、后续台词和少量资源差异呈现。

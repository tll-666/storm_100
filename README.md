# 暴雨100天

项目目前已经从2D俯视原型转入第一人称3D房屋实验。

## 目录

- `versions/2d/`：冻结的2D版本，可独立运行，只用于查阅、对比和回退。
- `versions/3d/`：当前主开发版本，使用Godot 4.7制作第一人称3D游戏。
- `docs/`：两个版本共用的设计讨论、机制、剧情和PRD文档。

## 打开项目

- 继续查看旧版：用Godot打开 `versions/2d/project.godot`。
- 开发当前版本：用Godot打开 `versions/3d/project.godot`。

根目录本身不再是Godot工程，避免编辑器误开旧版或重新生成一套混合缓存。
